2. Giải Pháp Công Nghệ

Mô hình: Kiến trúc Serverless (BaaS) giúp tối ưu hiệu năng và chi phí.


1. Giao diện (Frontend):

HTML5 / CSS3 Vanilla JS (ES6+) Tailwind CSS Chart.js

2. Hệ thống nền tảng (Backend - Firebase):

Firebase Auth Cloud Firestore (NoSQL) Real-time Data

3. Tích hợp API (Third-party):

LLM Chatbot AI Leaflet Map OpenWeatherMap

3. Chức năng hệ thống (Client-side)

  • Quản lý Giỏ hàng thông minh: Tính toán State bằng LocalStorage đảm bảo tốc độ phản hồi Zero-latency.
  • Bản đồ tương tác (Destinations): Trực quan hóa dữ liệu điểm đến bằng Leaflet.js kết hợp truy vấn Firestore.
  • Tùy chọn Add-ons (Upselling): Kiến trúc dữ liệu động cho phép khách hàng nâng cấp Khách sạn & Phương tiện ngay trong chi tiết Tour.

4. Phân hệ Quản trị (Admin)

  • Bảo mật đa lớp: Phân quyền Middleware tại Frontend kết hợp Firestore Security Rules.
  • Dashboard Thời gian thực: Sử dụng `onSnapshot` tự động đồng bộ khi có đơn hàng mới (Real-time).
  • Trực quan hóa Dữ liệu: Phân tích và kết xuất biểu đồ động bằng Chart.js.
  • Auto-Packaging: Tự động đóng gói cấu trúc dữ liệu JSON khi thêm Tour mới.
