INFRASTRUCTURE LAYER

Hạ Tầng Đám Mây Độc Lập `firebase-config.js`

Thông qua hai file `config-obj.js` và `firebase-config.js`, hệ thống khởi tạo kết nối an toàn trực tiếp đến Google Cloud Platform. Loại bỏ hoàn toàn sự phụ thuộc vào máy chủ ảo VPS truyền thống.

// Khởi tạo và Export Module ES6

import { initializeApp } from "https://www.gstatic.com/..."

const app = initializeApp(firebaseConfig);

export { auth, db }; // export luồng Auth & Firestore

Kiến trúc BaaS (Backend-as-a-Service)

Firebase đảm nhiệm vai trò lưu trữ cơ sở dữ liệu phi quan hệ, xác thực, giúp Frontend giao tiếp trực tiếp không qua Server trung gian.

GATEWAY AUTHENTICATION

Cổng Xác Thực An Toàn `login.html` & `register.html`

Quy trình đăng ký tài khoản được xử lý bất đồng bộ thông qua hàm khởi tạo `createUserWithEmailAndPassword`. Khi tạo tài khoản thành công, hệ thống áp dụng kỹ thuật kích hoạt đồng thời một hàm ghi cấu trúc phân quyền người dùng:

await setDoc(doc(db, "users", user.uid), { hoTen: name, role: "user" });

Mã hóa mật khẩu đầu cuối

Mặc định gán nhãn thuộc tính `role: "user"` để phân biệt quyền hạn một cách nghiêm ngặt với tài khoản quản trị viên `admin`.
